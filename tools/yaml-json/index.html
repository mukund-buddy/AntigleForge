How it works

        
Structure in, JSON out

      


      

        

          

            
Indentation is the map

            
Nesting is read purely from leading spaces, exactly like YAML expects. Tabs are rejected up front, so you never get a silently wrong structure.

          

        

        

          

            
Rich scalar support

            
Numbers, booleans, null, quoted strings, flow lists and maps, plus | and > block strings — each lands in JSON as the right type automatically.

          

        

        

          

            
Errors with a line number

            
Bad indentation, dangling quotes or stray content produce a human-readable message pointing at the exact line instead of a broken JSON blob.

          

        

      

    

  


  
  

    

      

        
Questions

        
YAML → JSON FAQ

      

      

        

          Which YAML features are supported?
          
A practical subset: nested maps and sequences, flow collections, single/double-quoted scalars, comments, and | or > block strings. Anchors, aliases and tags are not yet supported.

        

        

          How are errors reported?
          
With the exact 1-based line number and a human-readable message such as "Tabs cannot be used for indentation" — no more guessing where the config broke.

        

        

          Is my YAML uploaded?
          
No. Everything runs in your browser tab with no network calls, so password hashes, tokens and internal config can be converted privately.
