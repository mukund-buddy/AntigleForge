Potion Brewing Guide

Complete brewing reference for all Minecraft potions. Ingredients, effects, and durations.

Brewing Recipes
How brewing works: All potions start from an Awkward Potion (Nether Wart + Water Bottle). Add an ingredient to get the base effect, then optionally add Redstone (extends duration) or Glowstone (enhances effect but reduces duration). Add Gunpowder to make it Splash, or Dragon's Breath to make it Lingering.
