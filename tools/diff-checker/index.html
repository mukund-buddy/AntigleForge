How it works

        
Changes, made obvious

      


      

        

          

            
LCS alignment

            
A longest-common-subsequence comparison aligns both texts optimally, then groups the result into added, removed and unchanged runs for readable output.

          

        

        

          

            
Two precision levels

            
Word mode colours only the changed tokens inside a line; line mode lists whole lines with + / − signs. Switch at any time without losing your input.

          

        

        

          

            
Built for big inputs

            
When a comparison grows too large for the naive table, a fast prefix-locking pass keeps the page responsive instead of freezing.

          

        

      

    

  


  
  

    

      

        
Questions

        
Diff checker FAQ

      

      

        

          Word diff or line diff?
          
Line diff is ideal for code, configs and data files. Word diff highlights the exact changed tokens inside a sentence, which is clearer when comparing prose.

        

        

          How does it handle very large texts?
          
Once the input cross-product gets big, the diff switches to a fast path that keeps the matching prefix intact and reports the remainder as removed plus added — still accurate and instant.

        

        

          Is anything uploaded?
          
No. Everything runs locally in your browser, so drafts and confidential documents stay on your device.
