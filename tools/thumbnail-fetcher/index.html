How it works

How the thumbnail fetcher works

Paste a link

Any YouTube URL works: watch?v=, Shorts, live streams, embeds, music, or a bare youtu.be link. The tool extracts the 11-character video ID — it never guesses at random text.

Five sizes, checked honestly

Thumbnail URLs follow the pattern i.ytimg.com/vi/VIDEOID/SIZE.jpg. Because maxresdefault and sddefault don't exist for every video, the tool loads each one and reads its real pixel dimensions — a missing size is flagged instead of silently showing a grey placeholder.

Copy or open

Copy any size's URL with one click, or open it in a new tab to view it full size. The hqdefault size exists for every video and is the safest default.

Questions

Thumbnail fetcher FAQ

How do I get a YouTube thumbnail URL?

Paste any YouTube link — watch, short, live, or youtu.be — and the Thumbnail Fetcher extracts the video ID and builds direct thumbnail URLs for all five sizes: maxresdefault (1280×720), sddefault (640×480), hqdefault (480×360), mqdefault (320×180), and default (120×90).

Why is the maxresdefault thumbnail missing for some videos?

maxresdefault and sddefault are not generated for every video — older videos and some formats never received them. When a size is missing, YouTube returns a grey placeholder image instead of a 404 error, so the fetcher checks the actual image dimensions to tell you the truth.

Is the thumbnail fetcher free?

Yes. Every tool on AntigleForge is free and runs entirely in your browser. Nothing is uploaded, stored, or processed on a server.

Can I use thumbnails I fetch this way?

Thumbnails are created by the channel that uploaded the video, and usage is governed by YouTube's terms of service. The tool only gives you the URL — respect the creator's rights when reusing thumbnails.
