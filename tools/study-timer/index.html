    How it works
    
        
    Press start, study, repeat
    
      
    

      
    
        
    
          
    
            
    Pick a focus rhythm
    
            
    Pomodoro (25/5/15), Deep Focus (50/10/20), Quick (15/5) or Marathon (90/15/40). The cycle runs the rounds in order and slips a longer break between each set.
    
          
    
        
    
        
    
          
    
            
    Run and pause freely
    
            
    Start, Pause and Resume work as one button. Skip jumps to the next phase, Reset restarts the current cycle — and because deadlines use clock time, a background tab never shorts your session.
    
          
    
        
    
        
    
          
    
            
    Watch the totals grow
    
            
    Each finished phase becomes a line in the session log with its type and length. The totals and counts are recalculated instantly, so you know at a glance how much focus happened today.
    
          
    
        
    
      
    
    
    
  
    

  
  
    
    
    
      
    
        
    Questions
    
        
    Study timer FAQ
    
      
    
      
    
        
    
          Which preset should I pick?
          
    Start with Pomodoro (25 min focus with 5 min breaks, plus a longer one after four rounds). If 25 minutes feels too short, graduate to Deep Focus at 50; if you are warming up, use Quick at 15. Marathon is for long-form writing and exam cramming.
    
        
    
        
    
          Do sessions keep counting when I switch tabs?
          
    Yes. The timer counts real clock time (Date.now) rather than the number of page ticks, so a hidden tab or a slow device never makes a session run long. Come back to the tab and you will still be on time and on the dot.
    
        
    
        
    
          What does the log actually total?
          
    It counts every completed phase: focus vs break, each with its minutes. The top rows add total focus time, total break time, and how many completed phases and breaks happened this cycle. The copy button gives you that list as plain text.
