How it works

Markdown, minus the guessing

Block-aware tokeniser

Headings, fenced code, blockquotes, lists and paragraphs are detected line by line, then inline emphasis, code and links are parsed within each block.

Safe by construction

The preview pane is built from DOM nodes, never from raw HTML strings — anything that looks like markup is rendered as plain text.

Instant, private

Every keystroke re-renders locally with zero network traffic. Draft anything — from READMEs to personal notes — in total privacy.

Questions

Markdown preview FAQ

Which syntax is supported?

Headings (1–6), paragraphs, ordered/unordered lists, fenced code blocks with language tags, blockquotes, horizontal rules, and inline bold, italic, code and links.

Can raw HTML in markdown run scripts?

No. HTML-like text is rendered as plain text through safe DOM building — the preview is script-free by construction.

Is there a way to get the rendered HTML?

Not yet — but every tool here is free to use, and the renderer also powers the FAQ answers you are reading right now.
