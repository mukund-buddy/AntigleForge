How favicons work

One glyph, many sizes

The browser picks a size

Your tab icon, a bookmark, and mobile home-screen tile each ask for a different resolution. Providing every standard size means each viewer gets the crispest one.

PNG is the safe choice

SVG works in modern browsers but Apple and Android tooling expect exact-pixel raster images. The PNG set covers every platform, from 16px tab icons to 512px tiles.

Wire them in HTML

Add a <link rel="icon"> per size. 180px becomes apple-touch-icon, 192 and 512 feed the manifest for installed apps. Download the whole set and reference them once.

Questions

Favicon FAQ

Which sizes do I really need?

The practical minimum is favicon-16 and favicon-32 (tabs + bookmarks), then apple-touch-icon-180 and android-chrome-192/512 for phones and installed apps. Generating all six from this page covers every case.

Can I use a single-letter favicon?

Absolutely — a single letter or emblem glyph on a solid background is a classic, brandable mark. Type one character, pick a background, done.

Are downloads really generated locally?

Yes. The icon is drawn on a canvas in your browser and exported as PNG — nothing is uploaded and no server round-trip happens.
