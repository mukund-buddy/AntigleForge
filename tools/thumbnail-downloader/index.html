How it works

How the thumbnail downloader works

Pick a size

Five sizes are checked: maxresdefault (1280×720, when it exists), sddefault (640×480), hqdefault (480×360), mqdefault (320×180), and default (120×90).

See the real resolution

Each file is loaded and its actual pixel dimensions are read. If a size is missing — common for maxres and sd — it's flagged instead of shown as a grey box.

Save it

Tap Download to save the original file straight to your device — or press and hold the image and choose Save image. Open in new tab is a reliable fallback that never re-encodes the file.

Questions

Thumbnail downloader FAQ

How do I download a YouTube thumbnail in HD?

Paste the video link, pick a size tab (maxresdefault is the highest at 1280×720 when it exists), then tap Download — the original file is saved as-is. On phones you can also press and hold the preview image and choose Save Image, or tap Open in new tab. The tool always shows the real resolution the file is served at.

Why does my download come out grey or tiny?

maxresdefault and sddefault are not generated for every video. When a size is missing YouTube serves a 120×90 grey placeholder instead of an error, so the downloader checks each file's real dimensions, flags missing sizes, and disables Download for them. Use a size shown in full colour instead.

Is there a direct download button?

Yes. YouTube's thumbnail servers allow browser downloads, so the tool fetches the original file and saves it under a clean name like notgamingplayz-thumbnail-downloader-maxresdefault.jpg. If a browser blocks it (some iOS versions), the fallback is press-and-hold the image or Open in new tab → Save image as — the saved file is identical either way.

Does it work on phones?

Yes. On Android, tap Download and the file saves to your device. On iPhone or iPad, tap Download to open the save sheet, or press and hold the preview image and choose Save Image. Everything runs in your browser — nothing is uploaded anywhere.

Is the thumbnail downloader free?

Yes. Every tool on AntigleForge is free and runs entirely in your browser. Nothing is uploaded, stored, or processed on a server.
